A **store SEO audit** (App Store Optimization, or ASO) decides how easily users
find your app. Two listings with the same screenshots can rank very differently
based on how the title, subtitle, and keywords are written.

## What the audit checks

Toggle **ASO checks** in the tool to scan your listing for both stores:

- **Length limits** — App Store name (30) / subtitle (30) / keywords (100);
  Google Play title (30) / short description (80) — flagged when empty or over.
- **Keyword coverage** — primary terms present in the highest-impact fields.
- **Per-locale** — every locale audited separately, so a translated listing
  doesn't quietly lose its keywords.

## ASO tips it surfaces

- Put your strongest keyword near the **start of the title**.
- Don't repeat the app name in the keyword field — it's wasted space.
- Use the subtitle / short description for a second keyword theme.
- Keep each locale genuinely localized, not a copy of English.
